## Reading (descriptive)

- **A larger model does not fix what failed.** With the same harness, `qwen3:14b` builds the correct plan less than half the time and asks for a missing required value in 1 of 5 cases. Its latency is 3–4× higher, far above both latency levels.
- **Where it is better:** it restates fewer tool numbers in its own text (91 % against 76 %).
- **"Not documented" is 0 % for both models.** That is consistent with the harness diagnosis in `ai_n30_harness_fixes.md` (the search almost never came back empty), not with the model.
- **The safety rules hold for both:** 0 launches without confirmation, 0 invented numbers.
- **Consequence:** the harness, not the model's size, is the lever. F1.12 runs with the pinned `qwen3.5:9b` and the AI-N30 harness fixes.
