# VSC capacitor degradation: separability, Step 0 of D.2 (A4)

> **Epistemic warning.** No real reference dataset exists for capacitor degradation in this converter, unlike Paderborn for bearings. Every number below measures separability **of SPADE's own synthetic fault definition** (`sim/vsc_faults.py`: capacitance scaled, or an ESR added, in the exact ZOH of the L-C model). It is not evidence that a real degraded capacitor would be detectable.

Generated by `python experiments/verify_vsc_capacitor_separability.py [--noise-pct N]`; raw values: [`vsc_capacitor_separability.json`](vsc_capacitor_separability.json), [`_noise1pct.json`](vsc_capacitor_separability_noise1pct.json), [`_noise5pct.json`](vsc_capacitor_separability_noise5pct.json).

## Pre-registered rule (written in the script before any result)

- **Primary metric:** the out-of-fold AUC of a logistic regression separating healthy windows from windows with C = 80 % of nominal. The cross-validation is GroupKFold(5), grouped by operating point.
- **Cut:** if the AUC is below 0.70, stop D.2.
- **Closed loop:** the default DPC v4 runs it. It was trained for the nominal C.
- **Grid:** R = 8.0064, 20, 100 Ω × \|v_ref\| = 35, 50, 75 V × 4 phases, which gives 36 runs per level. Each run has 6 windows of 256 steps after a 300-step warm-up.
- **Features:** RMS tracking error, mean \|i_f\|, RMS \|v_o\|, active and reactive filter current relative to v_c, std of \|v_c\| and of \|i_f\|, RMS\|v_o\|/RMS\|v_c\|, and the known operating point (R, \|v_ref\|).

## Result

| Level | AUC (logistic, grouped CV) | Best single feature (AUC) | AUC with 1 % noise | AUC with 5 % noise |
|---|---|---|---|---|
| C_90pct | **1.000** | reactive_current (0.593) | 1.000 | 0.888 |
| C_80pct | **1.000** | reactive_current (0.697) | 1.000 | 0.975 |
| C_70pct | **1.000** | reactive_current (0.790) | 1.000 | 0.994 |
| ESR_0.05ohm | **0.510** | std_abs_i_f (0.509) | 0.515 | 0.520 |
| ESR_0.2ohm | **0.571** | std_abs_i_f (0.535) | 0.564 | 0.553 |

**Verdict (pre-registered): PROCEED: separable above the pre-registered cut.**

## Reading

**Capacitance loss is separable in this synthetic setting.**
- No single feature separates it well. The best one is the reactive filter current, AUC 0.59–0.79.
- Reactive current combined with the known operating point does separate it. The capacitive current is ωC·\|v_c\|, so at a known \|v_ref\| and R a smaller C shows up as a proportionally smaller reactive current. The closed loop does not hide it: the DPC tracks v_c and does not regulate i_f.

**The AUC of 1.0 is an upper bound.** The simulation has no measurement noise, no uncertainty in L or R_f, and the operating point is known exactly.
- The noise check is post-hoc and declared: complex Gaussian noise of 1 % or 5 % of each signal's RMS, applied to v_c, i_f and v_o before computing the features.
- With 5 % noise the AUC drops to 0.89 at C = 90 % and stays at 0.97 at the pre-registered 80 % level.
- Uncertainty in R, L or R_f was **not** tested. Each would shift the expected reactive current the way a capacitance change does.

**A series ESR of 0.05–0.2 Ω is not separable** (AUC 0.51–0.57). Its voltage drop is tiny next to the 2 Ω filter resistance and the load.

**Next step.** Under TODO A4 the classifier itself is **not** part of this task. The cut was passed, so it is proposed as a new task. That task should first add parameter uncertainty (R, L, R_f) and sensor noise to the dataset, and should treat ESR as not detectable with these signals.
