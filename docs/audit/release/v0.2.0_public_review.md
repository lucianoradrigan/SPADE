## What should not be public, or needs a decision

1. **The avatar screenshots are not covered by the avatar license.** The 13 files `docs/screenshots/assistant/avatar_*.png` show the likeness, but `licenses/avatar/LICENSE` lists only `base.webp` and `hand.webp`. As the license stands, the screenshots fall under the repository's MIT license.
   - **Proposal:** add `docs/screenshots/assistant/avatar_*.png` to the files covered in `licenses/avatar/LICENSE`, or remove the screenshots.
   - The license text is Luciano's, so this is not changed here. They are already public on `dev`.
2. **Two historical planning files tell Claude to add a co-author line,** which contradicts the current rule: `DECISIONES_EXPANSION_2026-10-21.md:73` and `PENDIENTES_EXPANSION_CLAUDE_CODE.md:46`. No commit carries one.
   - **Proposal:** a note "superseded: commits only as Luciano, without Claude attribution", or move those files out of the repository root.
3. **Internal planning documents in Spanish** sit at the root and in `docs/assistant/`: `TODO_*`, `PENDIENTES_*`, `DECISIONES_*`, `INSTRUCCIONES_CLAUDE_CODE_FASE1_2026-11-02.md`, and the ESPEC/PLAN files. They are not secret, but they are working notes in a public repository. A decision for Luciano: keep them, or move them to an `archive/` folder.
4. **Local paths:** `/home/seven/...` appears 32 times, in audit evidence, two `run_metadata.json` files (`dataset_path`) and two experiment scripts (a fallback data path). `CLAUDE.md` names `~/post_doc/plataform_proposed/...`.
   - This exposes only a user name and a folder layout. Low; can stay.
5. **Author e-mails** in the README and the citation: intended, and they match the app's citation, which a test checks.
